# 데스크톱 도름이 완료 로드맵

## 현재 기준

현재 실행물은 V98 통합 검수 쇼케이스입니다. Electron 창이 열리고 모션·자산 검수를 하지만, 출시 가능한 데스크톱 펫 앱은 아닙니다. 상세 원요구사항은 [`RELEASE-BACKLOG.md`](RELEASE-BACKLOG.md)에 있습니다.

## 1. 펫 동작과 표정

- 승인 클립 사이에 안전한 시작·종료·중단·복귀 전환을 구현합니다. 매 프레임 포즈가 끊기는 하드컷은 피합니다.
- 대기·이동·교감·작업·휴식·수면·이벤트 상태를 만들고 서로 맞지 않는 동작 조합을 막습니다.
- 정적 텍스처 표정을 연속 표정 보간으로 부르지 않습니다. 자연스러운 깜빡임, 고개·시선, 말하기 입 모양은 구현·검증 전까지 미완료로 둡니다.
- 바닥 클릭 이동, 화면 끝 회전/정지, 호출 반응, 속도 변화, 모니터 화면 좌표를 모델 root와 분리해 설계합니다.
- 손·머리 소품 동작은 개별 동작·프레임의 접촉을 검증합니다. 소품이 걸려 있거나 조합이 지원되지 않으면 이유를 알려줍니다.

## 2. 실제 Windows 데스크톱 기능

- 투명 영역 입력 통과와 펫 위 클릭 처리, 드래그 이동, 우클릭 메뉴, 숨기기/복귀, 항상 위 설정
- 트레이 메뉴와 종료 확인, 시작 프로그램 등록/해제, 마지막 위치·사용자 설정 저장
- 다중 모니터, 배율(DPI), 해상도/모니터 연결 변화, 작업 표시줄·전체화면·최소화 처리
- 배터리/절전 모드, reduced motion, GPU 자원 정리, 장시간 실행 후 메모리·프레임률 확인

## 3. 배포와 지원

- Windows clean VM/계정에서 설치·실행·설정·업데이트·제거 검증
- 코드 서명과 자동 업데이트 정책을 정하고, 설치·복구 안내를 제공
- 개발/검수/후보 자산을 설치물에서 분리하고 Meshy 키·개인 토큰을 배포물에 넣지 않음
- 자산 승인자, 모델/클립 해시, 릴리스 노트와 이전 버전 복구 경로를 기록

## 마일스톤 수락 기준

1. 움직임: 상태와 전환표, 정면·45도·측면 재생 캡처, 다리·발 접지/관통 결과
2. 표정: 전환/깜빡임이 실제로 재생되는 영상, 얼굴 자국·이중표정·위치 이동 없음
3. 데스크톱: 투명·클릭 통과·드래그·트레이·다중 모니터 실제 Windows QA
4. 배포: 새 환경에서 설치·실행·업데이트·제거, 바이너리/비밀정보 검사
5. 출시: 모든 필수 항목 통과 및 사용자 승인. 단순히 21개 클립/번호/화면이 있는 것으로 완료 처리하지 않음

각 마일스톤은 별도 PR로 올려 검토하고, 사용자 승인 자산 또는 출시 상태를 자동 확대하지 않습니다.
