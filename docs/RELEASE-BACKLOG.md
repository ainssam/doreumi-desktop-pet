# 도름이 데스크탑 펫 — 출시 제작 목록

작성일: 2026-09-14

목표: 원래 도름이의 외형을 유지하면서, 다양한 표정과 행동을 자연스럽게 연결하고 Windows 데스크탑에서 안정적으로 사용할 수 있는 3D 펫을 출시한다.

**현재는 출시 불가 상태다.** 팔·어깨 선행 결함은 V60에서 회전 재생 검수를 통과했지만, 발·나선·표정 전환, 소품을 사용하는 완결된 행동, 설치 프로그램은 아직 완료되지 않았다. 21개 애니메이션 클립이 있다는 사실만으로 실제 재생 검수나 출시가 끝난 것은 아니다.

체크박스는 ‘제작됨’이 아니라 ‘검수까지 통과함’을 뜻한다. 모든 제작 항목은 `미착수 → 제작 중 → 검수 중 → 수정 필요 / 통과`로 관리한다. 같은 문제가 다시 나오면 통과를 취소한다.

## 1. 제작 원칙과 외형 기준

- [ ] 43134 버전과 최초 레퍼런스 3장을 기준으로 정면·45도·측면·뒷면 기준 시트를 고정한다.
- [ ] 몸통 폭, 키, 머리·얼굴 비율, 팔 길이, 다리 간격, 눈·입 위치, 두 나선의 모양과 크기를 비교한다.
- [ ] 따뜻한 흰 몸, 짙은 남색 기본 나선, 검은 눈, 분홍 볼과 입의 색을 유지한다.
- [ ] 기본 표정은 두 눈을 뜬 모습으로 설계하고, 원래의 윙크도 동일한 얼굴 구조 안에서 구현한다.
- [ ] 발은 짧고 통통하게 유지한다. 발끝과 바닥 면은 조금 구분하되 신발·부츠처럼 길어지지 않게 한다.
- [ ] 모델·표면·소품 제작에는 Meshy를 우선 사용하고, 작업 ID·비용·결과·채택 여부를 기록한다.
- [ ] 기존 원본과 실패 후보를 보존하고 최종 실행기에 실패 후보를 섞지 않는다.
- [ ] 사용자가 허용한 관절 위치·연결·가중치 보완만 로컬에서 수행한다. 얼굴판이나 대체 나선을 덧붙여 외형 문제를 가리지 않는다.
- [ ] 고해상도 또는 최신 모델이라는 이유만으로 채택하지 않는다. 실제 외형과 움직임을 비교한다.

## 2. 현재 결함부터 해결 — 모든 동작의 선행 조건

- [x] 팔을 들 때 손이 납작해지거나 짧아지는 문제 해결. V60 Meshy 형상에서 둥근 손과 얕은 엄지를 유지하고 정면·45도·양측면·후면 및 손흔들기 영상을 통과했다.
- [x] 어깨 위·아래가 파이거나 몸통 옆면이 팔에 끌려가는 문제 해결. 화면 오른쪽인 도름이 기준 왼팔(`L`)의 V자 함몰을 V60의 넓고 볼록한 Meshy 연결부, 위쪽 관절 위치, 연속 harmonic 가중치로 제거했다. 응원 정면과 손흔들기 45도 실제 재생을 통과했다.
- [x] 짧은 단일형 팔에 맞게 `arm` 관절을 팔꿈치가 아닌 손 쪽 표면 변형축으로 재정의. 어깨축과 같은 소켓에 두되 형제 관절로 분리해 회전 누적을 제거함.
- [ ] 골반·무릎·발목·발끝의 위치를 외형과 맞춘다. 좌우 길이와 위치의 비대칭을 검사한다.
- [ ] 발목을 발바닥이 아닌 실제 굽힘 위치에 둔다. 발 디딤에서 발끝·뒤꿈치·바닥 면을 확인한다.
- [ ] 걷거나 뛸 때 다리 끝이 찢어지거나 톱니처럼 변하는 문제 해결.
- [x] 이동 기준점(root)을 해부학적 관절과 구분하고, 일반 사용자 화면에서는 숨긴다. 검수 오버레이에서는 주황 마름모와 `해부학적 관절 아님` 범례로 표시한다.
- [ ] 머리 관절 추가. 갸웃할 때 얼굴과 정수리 나선이 함께 움직이고 찌그러지지 않게 한다.
- [ ] 몸통 관절과 골반을 분리해 인사할 때 상체가 숙여지고 다리는 버티게 한다.
- [ ] 배 나선의 갈라짐, 정수리 나선의 이음선, 흰 띠, 파란 번짐, 접촉부의 검은 자국 해결.
- [ ] 색·발광 보정이 얼굴·흰 몸·나선 사이의 빈 공간까지 번지지 않게 한다.
- [x] 기본 자세에서 관절 보정 전후의 표면 위치·법선·UV·인덱스가 보존되는지 검사한다. V60에서 geometry attributes·materials·원본 binary payload 보존을 확인했다.
- [x] 정면·측면 관절 표시 캡처와 팔 최대 동작 캡처를 남긴다. V60 `final-joints-front.png`, `final-joints-side.png`, 손흔들기·응원 PNG/영상으로 보존했다. 다리의 모든 최대 동작 검수는 별도 항목으로 남는다.

## 3. 이동과 발 디딤

- [ ] 편안한 기본 서 있기: 아주 작은 호흡, 시선 이동, 가끔 눈 깜빡임.
- [x] 느린 ‘뚠뚠’ 걷기: 2.3초 주기, 완만한 발 들림·발 구름, 낮은 몸통 바운스. 45도 12초 영상과 한 주기 14프레임 통과.
- [ ] 보통 걷기와 목적지를 향한 산책.
- [ ] 신나는 달리기: 걷기와 구분되는 박자, 충분한 발 들림, 과도한 몸 늘어남 없음.
- [ ] 걷기 시작, 가속, 감속, 자연스럽게 멈추기.
- [ ] 걷다가 뛰기, 뛰다가 걷기로 전환.
- [ ] 왼쪽·오른쪽으로 돌기, 제자리 방향 전환, U턴.
- [ ] 몸이 향하는 방향으로 이동. 뒤로 미끄러지는 보행 제거.
- [ ] 화면 안에서 목적지를 골라 돌아다니기. 가장자리 앞에서 멈추거나 방향 바꾸기.
- [ ] 사용자가 누른 바닥 위치로 이동.
- [ ] 부르면 사용자가 지정한 위치로 달려와 멈추고 바라보기.
- [ ] 한 발을 살짝 들고 기다리기, 고개를 돌려 주변 살피기.
- [ ] 이동 거리와 발 주기를 연결해 발이 바닥에서 미끄러지지 않게 한다.

## 4. 기본 자세와 생활 동작

- [ ] 한 손으로 인사, 작게 손 흔들기, 반갑게 크게 손 흔들기.
- [ ] 양팔을 벌려 반기기, 조심스러운 두 손 인사.
- [ ] 상체를 숙이는 인사, 짧은 감사 인사, 깊은 정중한 인사.
- [ ] 바닥에 앉기, 다리를 앞으로 내밀고 쉬기, 앉아서 고개 돌리기, 일어나기.
- [ ] 고개 갸웃, 좌우 살펴보기, 끄덕이기, 가볍게 고개 젓기.
- [ ] 곰곰이 생각하기, 잠깐 멈칫하기, 아이디어가 떠오르기.
- [ ] 기지개, 양팔 스트레칭, 한쪽씩 몸 풀기.
- [x] 머리 뒤와 등을 바닥에 대고 배가 위를 향하는 ‘발라당 누워 쉬기’ 자세.
- [ ] 누운 자세에서 몸을 일으켜 다시 앉고 서는 자연스러운 전환.
- [ ] 데구르르 한 바퀴 구르기, 구른 뒤 자세 바로잡기.
- [ ] 제자리 작은 점프, 신나는 점프, 두 번 연속 작은 점프.
- [ ] 착지 뒤 균형 잡기. 바닥 관통이나 갑작스러운 튕김 제거.
- [x] 모니터 왼쪽·오른쪽에서 위치·몸 회전·고개 기울기를 반전해 몸을 절반만 내밀고 빼꼼 보기.
- [ ] 조심스럽게 숨기, 다시 나타나기. 화면 밖에서 영구적으로 사라지지 않기.
- [ ] 수줍게 손 모으기, 가슴에 손 얹기, 하트 안기, 응원하기.
- [ ] 박수, 작은 승리 포즈, 가벼운 리듬 타기, 짧은 축하 춤.
- [ ] 졸기, 하품, 잠들기, 기지개를 켜며 깨기.

## 5. 얼굴 표정과 입 움직임

얼굴 윤곽·눈·입의 원래 위치를 지키는 것이 선행 조건이다. 별도의 얼굴판이나 눈을 겹쳐서 기존 자국이 남는 방식은 불합격이다.

- [ ] 두 눈을 동그랗게 뜬 기본 얼굴.
- [ ] 자연스러운 양눈 깜빡임, 반쯤 감긴 눈, 원래 디자인의 윙크.
- [ ] 잔잔한 미소, 신나서 활짝 웃기, 눈을 접고 웃기.
- [ ] 눈이 반짝이는 기대감, 호기심, ‘오!’ 하는 놀람.
- [ ] 깊이 생각하기, 고민, 집중해서 코딩하기, 결심한 표정.
- [ ] 가볍게 찡그림, 불만, 삐침. 무섭게 변하지 않는 캐릭터다운 범위 유지.
- [ ] 슬픔, 속상함, 당황, 부끄러움, 안도, 뿌듯함.
- [ ] 편안함, 졸림, 잠든 얼굴, 갓 깬 얼굴.
- [ ] 입을 다문 기본형, 작은 아·오·우 발음, 미소를 띤 말하기, 하품.
- [ ] 말할 때 옹알옹알하는 입 움직임과 잠깐의 멈춤.
- [ ] 눈·입·볼·눈썹이 같은 감정을 표현하도록 조합을 설계한다.
- [ ] 기본 얼굴 ↔ 윙크 ↔ 웃음 ↔ 고민 사이의 부드러운 전환.
- [ ] 말하는 중에도 깜빡임·시선·고개 움직임을 독립적으로 조합한다.
- [ ] 작은 펫 크기에서 표정을 구분할 수 있고, 확대해도 자국·겹침·흐림이 없어야 한다.
- [ ] Meshy 결과로 연속 표정 전환을 구현할 수 있는지 별도 기술 검증한다. 정적인 표정 이미지 생성과 움직이는 3D 표정 완성은 구분한다.

## 6. 나선 색·빛·별가루

- [ ] 기본 남색, 다정한 분홍, 차분한 초록, 생각의 보라, 신나는 금빛, 편안한 하늘색.
- [ ] 보조 감정색: 수줍은 연보라, 놀란 산호색. 몸 전체의 색은 바꾸지 않는다.
- [ ] 머리·배 나선의 색과 발광을 감정에 맞춰 함께 전환한다.
- [ ] 색이 갑자기 튀지 않도록 부드럽게 변화하고 기본 남색으로 돌아온다.
- [ ] 나선 위를 빛이 천천히 지나가는 반짝임과 작은 빛 맥동.
- [ ] 걷는 중 은은한 반짝임, 달리는 중 더 분명한 발광과 별가루 꼬리.
- [ ] 점프·축하·아이디어 순간의 짧은 별가루 폭발.
- [ ] 몸에서 출발해 바깥으로 퍼지고 천천히 떨어지며 사라지는 별가루.
- [ ] 고개를 갸웃해도 정수리 나선에서, 몸을 숙여도 배 나선에서 정확히 발생한다.
- [ ] 어두운 배경·밝은 배경 모두에서 보이되 얼굴을 가리지 않는다.
- [ ] 강도 조절, 끄기, 절전·동작 줄이기 설정.
- [x] 봄에는 Meshy 원형의 다섯 꽃잎 꽃비가 천천히 내리는 연출.
- [x] 여름에는 둥근 투명 물방울이 올바른 방향으로 천천히 흔들리며 내리는 연출. 길고 가는 Meshy 빗줄기 원본은 보존하고 화면용 입자만 교체했다.
- [x] 가을에는 Meshy 원형의 잎맥 있는 낙엽이 회전하며 내리는 연출.
- [x] 겨울에는 Meshy 원형의 여섯 갈래 눈 결정이 천천히 내리는 연출.
- [x] 현재 월에 맞춰 계절을 자동 선택하고, 수동 선택과 끄기를 제공.

## 7. 완결된 상황별 행동

버튼을 눌러 포즈 하나를 보이는 수준을 넘어, 시작 → 행동 → 반응 → 원래 상태 복귀를 만든다.

- [ ] 부름: 이름/호출 버튼 인식 → 돌아보기 → 달려오기 → 감속 → 인사 → 기다리기.
- [ ] 생각: 멈추기 → 갸웃 → 고민 표정 → 나선 보라빛 → 아이디어 반짝임 → 반응.
- [ ] 코딩: 자리 잡기 → 앉기 → 노트북 펼치기 → 집중 표정·타이핑 → 성공/고민 반응 → 정리.
- [ ] 독서: 책 꺼내기 → 앉기 → 읽기 → 고개 끄덕이기 → 책 덮기. 현재 기본 앉기 진입은 1.45초 완만한 곡선과 작은 다리 비대칭·몸통/고개/손 호흡까지 브라우저 검수를 통과했다.
- [ ] 휴식: 산책 멈춤 → 앉기 → 스트레칭 → 눕기/졸기 → 깨기 → 일어나기.
- [ ] 축하: 사용자가 요청한 성공 이벤트 → 웃음 → 작은 점프/박수 → 별가루 → 안정.
- [ ] 응원: 사용자 바라보기 → 다정한 표정 → 손 모으기/하트 → 짧은 응원 말풍선.
- [ ] 명절 세배: 자리 잡기 → 두 손 모으기 → 무릎을 낮추기 → 상체와 고개 숙이기 → 일어나기 → 인사.
- [ ] 크리스마스 눈사람: 눈 뭉치 굴리기 → 몸통·머리 쌓기 → 장식하기 → 완성작 바라보기 → 손 흔들기.
- [ ] 빼꼼: 화면 가장자리로 이동 → 몸 숨기기 → 얼굴과 몸 일부 내밀기 → 시선·손짓 → 나오기.
- [ ] 대화: 호출 → 바라보기 → 듣는 반응 → 생각 → 말풍선·입 움직임 → 대기.
- [ ] 작별: 손 흔들기 → 화면 가장자리로 이동하거나 조용히 쉬기.

## 8. 소품과 레퍼런스 활용 버전

- [ ] 노트북·키보드, 책, 머그컵, 하트, 전구, 퍼즐, 지시봉, 칠판/작은 발표판, 눈사람 부품을 준비한다.
- [ ] 소품을 잡는 위치, 손과의 접촉, 바닥 위치, 꺼내고 넣는 전환을 검사한다.
- [ ] 레퍼런스의 손 들기, 가리키기, 소개하기, 생각하기, 공부, 휴식, 달리기, 하트, 춤, 발표 자세를 행동 목록과 연결한다.
- [ ] 교과 활용: 코딩·수학·과학·국어·영어·사회·역사·음악·미술·체육 버전.
- [ ] 활동 활용: 정보·진로·가정·환경·창의수업·융합수업·독서토론·로봇코딩·AI·메이커 버전.
- [ ] 위 활용 버전은 기존 도름이에 소품과 자세를 조합한다. 얼굴과 몸을 별개의 캐릭터로 다시 해석하지 않는다.
- [ ] 버전별 정적 PNG와 짧은 반복 영상, 필요한 경우 3D 모델·클립을 함께 정리한다.

## 9. 행동을 연결하는 펫 로직

- [ ] 기본 상태: 대기·산책·달리기·교감·생각·작업·휴식·수면·이벤트.
- [ ] 모든 상태에 진입, 유지, 종료 동작을 둔다.
- [ ] 행동 도중 호출되거나 다른 행동을 눌렀을 때 안전하게 전환한다.
- [ ] 달리는 중 즉시 앉거나, 누운 채 갑자기 서서 말하는 식의 순간 전환 방지.
- [ ] 표정·고개·몸동작·색·별가루·소품·말풍선을 하나의 상황에 맞게 조합한다.
- [ ] 맞지 않는 조합 제한: 잠든 얼굴로 전력 질주, 손에서 분리된 소품, 인사 중 엉뚱한 방향 보기 등.
- [ ] 행동 빈도·휴식 시간·같은 동작 반복 간격을 조절한다.
- [ ] 주의를 끄는 행동과 조용히 곁에 있는 행동의 비율을 설정한다.
- [ ] 너무 빠른 총총거림, 계속 꿀렁거림, 반복적인 큰 점프를 기본 행동에서 제거한다.
- [ ] 무작위 행동도 일정한 성격과 흐름을 가지도록 설계한다.

## 10. 실제 Windows 데스크탑 펫 기능

- [ ] 투명 배경, 부드러운 가장자리, 적절한 접지 그림자.
- [ ] 펫이 없는 영역은 뒤의 창을 클릭할 수 있게 한다.
- [ ] 펫 클릭·드래그·우클릭 메뉴, 원하는 위치에 놓기.
- [ ] 항상 위에 표시, 잠깐 숨기기, 다시 부르기, 종료.
- [ ] 화면 가장자리·작업표시줄 영역·이동 제한 범위를 처리한다.
- [ ] 다중 모니터, 서로 다른 화면 배율과 해상도, 모니터 분리·재연결을 처리한다.
- [ ] 창 크기나 배율이 바뀌어도 펫이 화면 밖에 고립되지 않게 한다.
- [ ] 크기·걷는 속도·활동량·별가루·소리·대화 표시 설정.
- [ ] 조용한 모드, 수면 모드, 전체화면 작업 중 방해 최소화.
- [ ] 트레이 메뉴, 시작 프로그램 등록/해제, 마지막 위치·설정 복원.
- [ ] 음성 호출을 지원한다면 사용자가 켠 경우에만 마이크를 사용하고 상태를 표시한다.
- [ ] 대화 엔진과 Meshy 제작 API를 구분한다. 배포 앱에 제작자의 Meshy 키를 포함하지 않는다.
- [ ] 대화 내역 보관 범위, 삭제, 오프라인 기본 행동을 명확하게 한다.
- [ ] 설치·첫 실행·업데이트·제거를 사용자가 쉽게 수행할 수 있게 한다.

## 11. 출시 전 검수

- [ ] 모든 동작을 정면·측면·45도에서 재생한다. 필요한 동작은 뒷면도 검사한다.
- [ ] 모든 머리 동작에서 얼굴과 정수리 나선의 형태를 확인한다.

- [ ] 모든 다리 동작에서 좌우 다리 구분, 발의 형태, 접지·미끄러짐·바닥 관통을 확인한다.

- [ ] 잘못된 설정, 네트워크 끊김, 대화 엔진 장애가 있어도 기본 펫 행동은 유지한다.

## 13. 진행 순서와 출시 판정

1. **외형과 관절**: 손·몸통 당김·발·나선 문제를 먼저 해결하고 정면/측면 캡처로 확인한다.
2. **기본 이동**: 이전 43134의 자연스러운 리듬을 참고해 걷기·달리기·멈춤·손 흔들기를 통과시킨다.
3. **자세와 전환**: 머리·몸통 관절을 활용해 앉기·인사·갸웃·스트레칭·눕기·구르기·점프를 검수한다.
4. **표정과 감정**: 원래 얼굴 구조를 유지하는 전환 방법을 검증하고 색·별가루와 연결한다.
5. **상황별 행동**: 소품, 호출, 코딩, 휴식, 세배, 눈사람, 대화를 완결된 행동으로 만든다.
6. **데스크탑 앱**: 상태 로직을 실제 투명 창·입력·화면 경계·설정과 연결한다.
7. **출시 검수와 패키징**: 실제 설치 환경과 장시간 재생을 검사하고 최종 자료를 만든다.

출시 불합격 조건: 얼굴/나선 변형, 손이나 발의 파손, 몸통이 팔에 끌려감, 지속적인 바닥 관통·미끄러짐, 부자연스러운 상태 전환, 창을 조작할 수 없는 문제, 실행 실패, 포함된 제작 API 키, 주요 요청 행동의 누락.

동작 개수·8K 텍스처·새 버전 번호만으로 출시 가능이라고 판정하지 않는다. 검수 영상과 실제 설치본의 동작이 기준이다.

## 14. 현재 증거와 남은 것

- V34: 사용자가 보행 리듬의 기준으로 지정. 원본 보존. 확대 검수에서 기존 한계가 있으므로 모든 동작에 무조건 재사용하지 않는다.
- V41: 가중치·관절 수정, 정면/측면 관절 캡처, 브라우저 녹화 수행. 사용자와 자체 검수에서 손·어깨 등 불합격. 완성본 아님.
- V42: 신발처럼 둥글고 분리돼 보이는 발 형태가 사용자 기준과 달라 외형 후보로 불합격. 관절·20개 클립·색/효과 구현은 다음 버전의 기반으로만 보존.
- V43: Meshy에서 다리 끝이 아주 조금 접힌 새 전신 후보를 생성하고 메시·재질을 보존한 관절 재가중치와 21개 클립을 연결했다. 독서 앉기와 여름비 등은 보존하지만, 2026-09-15 회전 확대에서 도름이 기준 왼쪽 어깨의 깊은 파임이 중립 자세부터 확인되어 팔 항목은 불합격으로 다시 열었다. 정면 캡처만으로 내렸던 팔 통과 판정은 취소했다.
- V45: Meshy 7 Ultra·8K 네이티브 형상과 승인 레퍼런스 재질 후보를 별도 생성했다. 형상과 기본색은 매끈하지만 PBR 노멀맵이 나선에 흰 요철을 만들어 현재 모델로 채택하지 않았다.
- V60: V50의 매끈한 Meshy 네이티브 어깨 형상과 V59 미드나이트 스타일을 결합하고, 외형을 바꾸지 않은 관절 위치·연속 harmonic 가중치를 적용했다. 정적 4방향, 정면·측면 관절 오버레이, 손흔들기 45도, 응원 정면, 걷기 45도 실제 재생을 통과해 `/motion-review` 기본 모델로 승격했다. 이번 Meshy 계보는 293크레딧을 사용했으며 작업 ID와 채택 여부는 `deliverable/dorms-v60-final-shoulder/reports/meshy-lineage.json`에 기록했다. 이는 팔·어깨 게이트 통과이며 전체 출시 판정은 아니다.
- 사계절 원형: Meshy Image-to-Image로 꽃·빗방울·낙엽·눈송이 투명 PNG를 각각 생성하고, 원본을 보존한 채 런타임에서 가볍게 복제한다.
- 새 Meshy 자동 리깅: 정수리 수치 검사 개선과 별개로 실제 재생에서 배 나선 변형 재현. 그대로 채택하지 않는다.
- 다양한 연속 3D 표정, 실제 소품 접촉, 완결된 상황별 행동, 대화 연결, 출시 패키지는 아직 완료되지 않았다.
