# V90 — 실제 V60에 승인 표정 34종 적용

로컬 주소: http://127.0.0.1:43190/

V89에서 사용자가 수용한 얼굴 내부 보정값을 그대로 재사용한다. 몸·관절·클립은 V60이며, V34 기반 표정 모델의 몸을 대신 표시하지 않는다. 원본 GLB와 텍스처는 수정하지 않고, V60 뷰어 메모리에서만 고정 보정값과 표정 무늬를 적용한다.

## 사용

표정 선택 또는 좌우 화살표로 34종을 전환한다. 승인 원본 사진·버전·원본 경로를 함께 표시한다. 정면/45도/측면/뒷면, 얼굴/전신, 확대, 원본 복원, 굴곡 확인, 행동 재생과 스크럽, 캡처·녹화를 제공한다.

통과/수정 필요/보류 및 메모는 표정별로 해당 브라우저에 저장된다. 전체 판정 JSON을 내보낼 수 있다. 브라우저 저장소를 지우면 판정도 사라지므로 JSON을 별도로 보관한다.

## 실제 읽은 자산과 승인 경계

- V60 `../dorms-v60-final-shoulder/models/basic.glb`: 화면 양쪽의 실제 모델, 원본 관절·21개 클립 보존. 파일 존재가 모든 클립의 승인을 뜻하지 않는다.
- V86 `../dorms-v86-approved-expression-set/APPROVED-MANIFEST.json`: 정적 승인 34종의 GLB·텍스처 해시와 구조/UV를 검사한다. 목록 전체와 절대 경로는 `reports/source-audit.json`에 기록했다.
- 브라우저는 기본 표정의 GLB를 비표시 투영 기준으로 한 번 읽고, 승인 텍스처 34종을 실제 로딩해 V60에 적용했다. 각 표정의 전체 GLB 34개를 화면에 로딩한 것은 아니다.
- 생각과 말하기 우는 V84 수정본. 안도는 기쁨, 수줍음은 부끄러움으로 표시한다.
- V89의 위치·법선 보정 파일을 고정 SHA256으로 검사한다. V90에서 새 보정값을 생성하거나 기존 값을 수정하지 않았다.
- 원본 정적 승인 34종 / V60 적용 결과 사용자 승인 34종. 2026-09-20 사용자의 “전부 통과시켜도 될듯”에 따라 일괄 통과 처리했다. 자산별 판정·원본 해시·고정 보정값은 `USER-APPROVAL.json`에 기록했다. 기존 검수 보고서와 브라우저 화면의 검수 대기 문구·로컬 메모는 승인 전 상태로 남아 있으며, 현재 사용자 승인 상태는 이 승인 기록을 기준으로 한다.

## 가능한 것과 남은 것

34종 정적 표정 + 기존 V60 행동을 동시에 표시한다. 생각+갸웃(후보), 응원+응원 동작, 인사 미소+인사, 울먹임+걷기의 대표 프레임을 검사했다. 갸웃 후보를 새로 승인하지 않았다.

연속 표정 보간·자연스러운 깜빡임·음성 립싱크는 없다. 표정 전환은 정적 교체다. 소품·계절·효과까지 V90에 연결하는 작업은 하지 않았다. 기존 V87 통합 쇼케이스와 출시 실행기는 수정하지 않았다. 독립 배포용 GLB 출력도 없다.

## 재실행과 증거

이 폴더에서 `node serve.mjs` 실행. 기존 V87/V88/V89의 읽기 전용 모듈 및 자산을 참조하므로 이 폴더만 이동하지 않는다.

- `node --test pigment.test.mjs`: 표정 추출 테스트
- `node manifest.mjs --audit`: 승인 원본/구조/고정 보정값 검사
- `node browser-qa.mjs`: 실제 Chromium 34종·3방향·행동·저장·복원 검사
- `reports/browser-validation.json`: 실제 로딩 목록, 캡처, 오류 결과
- `evidence/v60-front-sheet.jpg`, `v60-quarter-sheet.jpg`, `v60-side-sheet.jpg`: 34종 비교
- `evidence/cheering-cheer.webm`: 실제 재생 녹화. 헤드리스 저프레임 기록이며 출시 성능 증거가 아님.

Meshy 신규 요청/크레딧 사용 0, 원본 덮어쓰기 0, 출시 연결 없음.
