# 도름이 V48 — 감성형 Meshy 소품 후보

V47의 텍스트 전용 소품에서 거친 결과가 확인되어, 제공된 마스코트 보드를 시각 품질 기준으로 사용하는 분리 후보 묶음이다.

1. Meshy 이미지 생성으로 소품의 감성·색·실루엣이 담긴 단일 콘셉트 이미지를 먼저 만든다.
2. 그 Meshy 작업 ID를 입력으로 Meshy 7 Ultra 3D·8K 재질 GLB를 만든다.
3. 썸네일과 실제 GLB를 검수한 뒤에만 다음 장면에 연결한다.

도름이 본체의 외형, 얼굴, 나선, 메시, 재질, 관절과 기존 실행기는 수정하지 않는다. 불합격 후보도 삭제하거나 덮어쓰지 않는다.
