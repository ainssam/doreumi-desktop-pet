# 도름이 V98 통합 검수

승인된 V60 모델 위에서 표정, 행동, 소품, 가슴 배지, 계절 효과와 나선 색을 함께 확인하는 로컬 전용 검수 화면이다.

## 실행

```powershell
npm start
```

- 기본 주소: `http://127.0.0.1:43198/`
- 데스크톱 창: `npm run qa:desktop`은 검증용이며, 실제 창 실행은 프로젝트의 Electron 진입점 `desktop.cjs`를 사용한다.
- 원본 GLB와 텍스처는 읽기 전용으로 참조한다.

## 자산 경계

- 몸·관절·승인 행동: V60 `basic.glb`, 21개 사용자 승인 클립
- 표정: V86 승인 목록을 V60에 이전한 34종
- 장착·배치 소품: V48/V42 기반 17종, 현재 후보 검수 자산
- 가슴 배지: V97 20종, 현재 후보 검수 자산
- 계절: 봄·여름·가을·겨울 기존 런타임 텍스처
- 나선 색: 남색 기본 및 빨주노초파남보·검정 계열 검수 효과

후보 소품과 배지는 기본 화면에서 숨겨지며 `후보 보기`를 켜야 선택할 수 있다. 이 화면의 통과는 배치·동작 호환성 검수 결과이며, 후보를 출시 승인 자산으로 자동 승격하지 않는다.

## 검증 명령

```powershell
npm test
npm run qa
npm run qa:motion
npm run qa:desktop
```

증거는 `evidence/`, 기계 판독 보고서는 `reports/`에 저장된다.
