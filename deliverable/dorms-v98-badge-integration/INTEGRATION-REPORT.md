# V97 배지 → V98 V60 통합 보고

- V97 원본 20개 GLB와 해시를 검증하고 원본은 변경하지 않았다.
- 배지는 머리·손·장면 소품과 별개인 `chest` 단일 슬롯으로 구현했다.
- V34 좌표를 재사용하지 않고 현재 V60 스킨 표면을 레이캐스트해 삼각형·바리센트릭 좌표를 다시 계산했다.
- 장착점은 얼굴판과 가슴 나선을 피해 오른쪽 가슴에 두고, 애니메이션 중 스킨 변형을 따라간다.
- 배지 뒷면과 V60 표면의 중심 간격은 0.006 단위이며, 20종 모두 동일한 규격으로 교체된다.
- 선택 해제와 후보 모드 끄기에서 배지가 제거되고, 다른 슬롯은 독립적으로 유지된다.
- 대표 동시 조합 `겨울+산타 모자+선물 주머니+첫 인사 배지`, `응원+매화 장식+요술봉+메이커 배지`, `코딩+컴퓨터+코드 배지`를 정면·45도·측면에서 검증했다.
- 브라우저와 Electron에서 콘솔 오류·요청 실패 없이 로딩됐다.

이 버전은 로컬 검수·출시 실행기 연결 상태를 검증하는 결과다. V97 배지를 승인·보상 시스템이나 공개 배포에 자동 연결하지 않는다.
