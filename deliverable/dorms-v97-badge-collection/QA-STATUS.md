# V97 배지 20종 제작 검수

## 완료

- Meshy 공통 틀 1개, 참고 이미지 20종, 이미지 유도 텍스처 GLB 20종 생성·다운로드.
- 늦어진 등대 참고 이미지의 대체 시도 1건 추가. 원본이 뒤이어 먼저 완료되어 원본을 사용했고, 대체 이미지도 삭제하지 않고 보존.
- 이번 API 보고 사용량 414 크레딧: 공통 틀 25 + 이미지 21 × 9 + 모델 재질 20 × 10. 이전 V95/V96 95 크레딧은 별도.
- 20개 GLB 헤더·파일 해시·실제 지오메트리 검증 통과.
- 최종 20종의 삼각형 표면 해시 동일. 18,028개 삼각형, 크기 약 1.9996 × 2 × 0.14684 모델 단위.
- Meshy UV 재생성 결과는 최초 base와 정규화 및 면 수가 달라 바이트 동일하지 않음. 최종 배지 상호 형상은 동일.
- 앞면 중앙 +Z 약 0.07165, 75~90% 반경 영역의 최대 +Z 약 0.05213. 앞면 중앙의 미세한 볼록함과 둥근 테두리는 실제 형상.
- Playwright로 20종 × 정면/45도/측면/뒷면 총 80장 캡처. 모델 로딩 및 pageerror 0. 목록 시트 `evidence/collection-20.png`를 직접 확인.
- 20개 문양 식별 가능. 밝은 배경·색상 계열 유지. 새 이미지 유도 방식으로 이전 풍경 장식 제거.

## 표시와 한계

- 배지 외곽의 볼륨은 실제 3D. 중앙 문양은 별도 양각 메시가 아닌 텍스처 표현.
- 원본 노멀맵을 켜면 삼각형 반사가 과해 보여 기본 미리보기에서만 비활성. metalnessMap off, metalness 0, roughness .38. 지오메트리/원본 GLB 파일은 수정하지 않음.
- 확대 시 일부 가장자리 텍스처 이음선이 남음. 완전한 제품 출시 품질 승인으로 보고하지 않음.
- 현재까지 배지 단독 형상·텍스처 검수 완료. 최신 V60 계열의 움직임·소품 동시 부착은 통합 검수 작업이 담당.
- 미션 문구는 기획안이며 실제 홈페이지의 지급 시스템은 구현하지 않음.
