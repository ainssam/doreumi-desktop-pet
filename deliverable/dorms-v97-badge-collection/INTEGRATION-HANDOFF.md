사용자 요청: “배지를 다 만든 다음에는 검수 채팅 페이지로 옮겨서 부착 한 상태 + 움직임 + 소품 연결해줘.”

연결 대상 작업: `도름이 통합 검수 페이지 만들기`, ID `01a0bc3f-28ae-7433-b3a5-3e5150d1f679`.

## 파일과 소유 범위

이 배지 작업은 `deliverable/dorms-v97-badge-collection/`만 제작합니다. 통합 작업은 현재 자신의 검수 페이지 및 별도 후속 버전을 맡으며 V97 원본을 덮어쓰지 않습니다. `integration-manifest.json`이 있고 `readyForIntegration: true`, `count: 20`인 때에만 전체 컬렉션 연결 준비가 완료된 것입니다.

- 모델: `models/{id}.glb` 20종
- 실제 3D 정면·45도·측면·뒷면 캡처: `evidence/{id}-{view}.png`
- 디자인 참고 이미지: `references/` (3D 렌더와 구분)
- API 작업 ID·원본 해시·사용량: `reports/generation.json`
- 형상 비교: `reports/validation.json`

## 모델·재질 경계

배지 공통 원형 형상은 Meshy에서 생성했습니다. 앞면 중앙이 주변보다 미세하게 볼록하고 테두리는 둥급니다. 아이콘 자체는 별도 양각 메시가 아니라 재질 표현입니다. 로컬 메시 조형은 하지 않았습니다.

Meshy의 새 UV 생성 단계가 원래 공통 틀을 정규화하고 면 수를 9개 줄였습니다. 따라서 최초 base와 바이트 동일로 보고하지 마세요. 최종 배지끼리 동일한 삼각형 표면을 갖는지는 manifest 및 validation에서 확인할 수 있습니다.

표시 재질: base color 보존, normalMap 비활성, metalnessMap 비활성, metalness=0, roughness=.38. 원본 노멀맵에서 생기는 과한 삼각형 반사 자국을 줄이는 표시 설정입니다. GLB 파일은 수정하지 마세요. 기존 검수 페이지 조명에서도 채도와 볼륨을 확인하세요.

## 부착·동시 조합

1. 기존 검수 페이지의 승인된 최신 모델·동작·표정·소품을 유지합니다. 이전 V34 착용 목업으로 모델을 되돌리지 않습니다.
2. `chest` 독립 슬롯 추가. 선택한 배지 하나 또는 미착용. 머리·손·배치 소품과 독립적으로 선택합니다.
3. 현재 V60 계열 몸통의 변형 표면 삼각형/바리센트릭 좌표로 가슴 앵커를 구합니다. V34 좌표를 복사하지 않습니다.
4. 얼굴과 가슴 나선을 가리지 않고, 기존 소품과 관통하지 않는 크기·위치를 정합니다. 정면·45도·측면으로 검수합니다.
5. Idle/Walk/Wave 등 현재 지원 동작과, 대표 승인 소품 조합을 실제 재생해 배지가 몸에서 떠 있거나 미끄러지지 않는지 확인합니다. 동작 원본 수정은 하지 않습니다.
6. 작은 정지 캡처 외에 배지 착용 + 움직임 + 소품이 함께 보이는 녹화 또는 GIF를 남깁니다. 미착용 전환과 배지 변경도 검사합니다.
7. 사용자 스타일 선택과 전체 조합 승인/출시 승인은 구분합니다. 연결은 검수용이며 공개 배포나 설치 실행기 출시를 자동 수행하지 않습니다.

완료 후 검수 페이지 주소·산출물 경로·검사 결과·남은 한계를 이 배지 작업에 알려 주세요.
